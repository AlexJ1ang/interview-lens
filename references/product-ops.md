# 产品 / 运营岗题库与出题方法论

## 一、出题方法论

产品/运营岗考察的不是"标准答案"，而是**思考框架、用户视角、数据意识、结构化表达**。面试官重在引导候选人展开思考，追问"为什么""怎么验证""换你会怎么做"。

- **一面（基础）**：岗位认知、基础方法论、通用能力、简历项目。
- **二面（深化）**：业务题、案例分析、数据分析和方案设计；若用户选择项目深挖模式，再以项目为主线考察。
- **三面（总监/交叉）**：商业视野、战略判断、跨团队协作、价值观。

## 二、高频考点清单

### 1. 产品思维与基础
- 需求分析：如何判断需求真伪、优先级（KANO 模型、价值/成本）、用户调研
- 产品设计：MVP、A/B 测试、用户体验五要素、漏斗模型
- 方法论：用户画像、场景拆解、竞品分析、北极星指标

### 2. 数据分析（运营岗尤重）
- 常用指标：DAU/MAU/留存/转化率/复购/GMV/LTV/ARPU/ROI/激活率/流失率
- 分析方法：漏斗分析、同期群（cohort）、RFM 模型、北极星、拆解（OSM）
- 经典题：某指标下降怎么分析、如何评估一次活动效果、留存低怎么破
- SQL 基础（产品/策略岗常考）：连表、聚合、窗口函数

### 3. 案例分析 / 业务设计题（高频）
- "设计一个 XX 功能/产品"（如"给老年人设计一个打车功能"）
- "估算类"（费米估算：如北京市一年卖多少杯奶茶）
- "改进类"（如"给某 App 提三个改进点"）
- "商业化"（如"怎么给免费产品设计变现"）

### 4. 运营专项
- 用户运营：拉新/促活/留存/召回、会员体系、积分体系
- 内容/活动运营：活动策划、裂变玩法、内容调性
- 渠道与增长：投放、SEO/ASO、私域、社群
- 策略运营：补贴策略、风控、AB 实验

### 5. 项目评估
- 综合模拟需要项目题时，用 STAR 补齐最关键的一个缺口；项目深挖模式才连续考察职责、目标、拆解、行动、结果和复盘。

## 三、示例题与答案要点

**例 1：如果某 App 的次日留存率突然下降了 5%，你怎么分析？**
答案要点（考察分析框架）：先定位（整体还是某渠道/版本/人群）→ 拆维度（新老用户、渠道、机型、地域、时间点）→ 查变更（是否有新版本上线、活动结束、竞品动作）→ 定性归因（数据 + 用户反馈）→ 给对策。追问：如果发现是某渠道新增用户质量差，怎么验证和解决。

**例 2：给你 10 万预算，怎么在 3 个月内让一个 0 基础新产品的 DAU 从 0 做到 1 万？**
答案要点（考察增长拆解与落地）：定义目标用户与核心价值 → 拆解 DAU 公式（新增×留存）→ 选增长策略（免费/内容/社交/投放/裂变）→ 分阶段规划 → 设定北极星指标与验证点。追问：为什么不用付费投放、冷启动第一波用户怎么来。

**例 3：估算一下北京市一年卖出多少杯奶茶。**
答案要点（费米估算，看重拆解逻辑而非准确答案）：可用“人口 × 目标人群占比 × 人均年购买频次”，或“门店数 × 日均出杯量 × 365”。估算杯数时不要乘单价；只有估算销售额时才加入客单价。关键是给出合理假设、自洽链条并说明误差来源。追问：假设没数据时如何获取，误差最大的环节是哪。

**例 4：设计一个面向老年人的打车功能。**
答案要点：先讲目标用户痛点（不明位置/不会操作/担心安全/视力）→ 核心功能（一键呼叫、语音、大字、家人代叫、固定上车点）→ 优先级 → 验证方式。追问：为什么优先做家人代叫而不是语音、如何验证需求。

**例 5：说出你简历里最满意的一个项目，你的贡献是什么？**
答案要点：STAR 完整、强调个人贡献与量化结果、有反思。追问：数据是怎么来的、如果你重做会改什么、和协作的边界在哪。

**例 6：如何判断一个需求该不该做？**
答案要点：用户价值（谁、多痛、频次）vs 商业价值（投入产出）vs 成本（开发/运营）+ 优先级排序工具（价值/成本四象限、KANO、RICE）。追问：给出一个你砍掉无效需求的例子。

## 四、追问技巧

- 案例题重在追问"为什么""数据从哪来""怎么验证"，逼出思考深度而非套模板。
- 项目题用 STAR，并追问个人贡献（"你"做了什么 vs "团队"做了什么）。
- 费米估算追问某个假设的依据，考察是否只会背套路。
- 反问"如果资源/时间砍半，你怎么取舍"，考察优先级与取舍力。
- 提示加分项：是否有数据敏感度、是否先定义问题再解决、是否考虑用户而非自嗨。
