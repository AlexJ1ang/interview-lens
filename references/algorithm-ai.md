# 算法 / AI 工程师岗题库与出题方法论

## 一、出题方法论

算法/AI 岗分两条线，先确认候选人是偏"机器学习/AI 应用"还是偏"算法研发/研究"，再定侧重：
- **基础线**：数学与统计、算法思想、实验设计和编程基础；不安排现场手撕算法。
- **AI 线**：机器学习理论、深度学习、模型训练/调优和大模型（LLM）工程；项目深挖仅在对应模式中作为主线。

按轮次：一面考基础与核心概念，二面考模型细节、实验诊断和工程落地，三面考研究视野与技术判断。项目材料可以辅助选题，但只有项目深挖模式才连续围绕项目追问。

## 二、高频考点清单

### 1. 算法思想与问题求解
- 讨论常见算法范式、复杂度、数据结构选择和适用边界，但不要求现场写代码。
- 可用已有伪代码、实验结果或系统场景，让候选人判断瓶颈、正确性和改进方向。
- 研究向候选人重点考察问题形式化、基线选择、假设、实验控制和结果解释。

### 2. 数学与统计基础
- 概率论：贝叶斯、条件概率、期望、大数定律、常见分布（正态/伯努利/泊松）
- 线性代数：矩阵、特征值/特征向量、SVD、PCA 原理
- 信息论：熵、交叉熵、KL 散度、互信息
- 最优化：梯度下降及变体（SGD/Momentum/Adam）、学习率、收敛性、凸优化基础

### 3. 机器学习
- 经典算法原理：线性回归、逻辑回归、SVM、决策树/随机森林/GBDT/XGBoost、KNN、朴素贝叶斯、聚类（KMeans）
- 核心概念：过拟合/欠拟合、偏差-方差、正则化（L1/L2）、交叉验证、特征工程、评估指标（精确率/召回率/F1/AUC/ROC）
- 追问：为什么 XGBoost 快、L1 为什么稀疏、AUC 含义、样本不平衡怎么处理

### 4. 深度学习
- 基础：反向传播、激活函数（ReLU/GeLU/Sigmoid）、损失函数（CE/MSE）、归一化（BN/LN）、Dropout、优化器
- 网络结构：CNN（卷积/池化/感受野）、RNN/LSTM/GRU、Transformer（自注意力多头注意力、位置编码、残差、LayerNorm）、残差网络
- 训练技巧：学习率调度、warm-up、梯度消失/爆炸、混合精度、早停

### 5. 大模型（LLM）与 NLP（当下热点，强烈推荐）
- Transformer 细节：QKV、缩放点积、多头、为什么除以 sqrt(dk)、FFN 作用
- 训练：预训练/指令微调（SFT）/RLHF（PPO/DPO）、LoRA/QLoRA、量化
- 推理与工程：KV Cache、注意力优化（FlashAttention）、显存估算、部署（vLLM）、RAG、Agent、函数调用、Prompt 工程
- 模型对比：GPT/Llama/DeepSeek/Qwen 等架构差异（如 RoPE、GQA、MoE）
- 评测：困惑度、常用 benchmark、如何评估生成质量

### 6. 项目评估（项目深挖模式）
- 数据：数据规模、质量、清洗、标注、分布漂移
- 模型：为什么选这个结构、baseline、如何调优、消融实验
- 指标：业务指标 vs 模型指标、离线/在线一致性
- 落地：延迟、成本、工程化、上线后监控与迭代

## 三、示例题与答案要点

**例 1：Transformer 里为什么要除以根号 d_k？**
答案要点：防止点积值过大导致 softmax 梯度消失、进入饱和区；缩放后梯度更稳定。追问：多头注意力的作用、位置编码为什么需要、RoPE 相对位置编码原理。

**例 2：L1 和 L2 正则化的区别？**
答案要点：L1 加绝对值、L2 加平方。L1 更容易产生稀疏解（几何上菱形与等高线交点落在坐标轴上），可做特征选择；L2 让权重平滑、抑制过拟合并稳定解。追问：为什么 L1 稀疏、弹性网络。

**例 3：过拟合怎么判断、怎么解决？**
答案要点：判断看训练/验证 loss 或指标 gap。解决：更多数据、正则化、Dropout、早停、降低模型复杂度、数据增强、交叉验证。追问：Dropout 为什么有效（类似集成）、测试时是否用 Dropout。

**例 4：说说 attention 和它为什么有效？**
答案要点：通过 QK 相似度计算注意力权重，对 V 加权求和，让模型动态关注重要位置并建模位置间依赖。追问时区分两类优化：稀疏/线性注意力尝试改变计算结构或复杂度；FlashAttention 通过 IO 感知的精确注意力实现降低内存访问和中间存储开销，不能笼统说成把稠密注意力变为次二次计算。

**例 5：一个离线指标提升但线上效果下降的模型，你会如何定位？**
答案要点：先核对指标定义与数据链路，再检查训练/服务特征一致性、数据漂移、切分与泄漏、阈值、延迟和业务反馈；通过分群、回放、消融或 A/B 实验缩小范围。追问：如何区分模型问题与工程问题、怎样设计回滚和监控。

**例 6：BN 和 LN 的区别？为什么 Transformer 用 LN？**
答案要点：BN 沿 batch 维度归一化、依赖 batch 大小且不适合变长序列；LN 沿特征维度、对单个样本归一化，天然适配序列和 batch 小/变长场景，故 Transformer 用 LN。追问：训练/推理时 BN 的差异、LN 公式与可学习参数。

**例 7：讲讲 RAG 和它要解决什么问题？**
答案要点：检索增强生成，解决 LLM 知识时效性、幻觉、私有知识问题。流程：文档切分→向量化→检索 TopK→拼接上下文→生成。追问：如何提升检索质量、chunk 策略、召回与重排、如何抑制幻觉。

**例 8：样本极度不平衡怎么处理？**
答案要点：数据层（重采样/过采样如 SMOTE、欠采样）、算法层（代价敏感、Focal Loss）、评估层（换指标如 AUC/F1 而非 Accuracy）。追问：Focal Loss 原理、SMOTE 原理与风险。

## 四、追问技巧

- 对算法思想追问复杂度、假设、边界和替代方案，但不要求现场写代码。
- 模型题追问"为什么这么设计""有没有替代方案""trade-off 是什么"。
- LLM 方向多追问工程落地：显存怎么算、延迟怎么压、怎么量化、怎么评估生成效果。
- 项目深挖模式可结合 STAR，围绕线上指标下滑、失败实验或模型选型持续追问；其他模式最多把这些内容作为单道项目题。
- 考察是否只会背答案：换一种问法或给具体数据场景验证是否真理解。
