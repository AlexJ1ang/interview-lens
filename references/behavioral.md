# 行为面 / HR 面通用方法论与题库

适用于所有岗位的通用面试环节：自我介绍、项目经历、动机与岗位匹配、薪酬沟通和反问环节。

## 一、STAR 追问法（项目深挖核心工具）

需要评价项目或经历时，按 STAR + Reflection 检查回答缺少的部分，不必逐项追问。追问次数遵循当前强度配置；只有项目深挖模式才把多个主问题连续用于同一个项目：

- **S (Situation)**：背景是什么？规模多大？当时的目标/约束？
- **T (Task)**：你的具体任务和职责是什么？区分团队成果和个人贡献，但不要使用敌意话术。
- **A (Action)**：你具体做了什么？你的决策？为什么这么做？
- **R (Result)**：结果如何？优先使用可靠的量化指标；没有数字时接受用户反馈、交付结果、行为变化等可说明的定性证据，不鼓励编造数据。
- **R (Reflection)**：如果重来一次会怎么做？踩过什么坑？

追问话术示例：
- "这个项目里，你个人独立负责的部分是什么？"
- "你说的'效果很好'，具体数据是多少？"
- "如果资源减半 / 时间剩一周，你会砍掉什么？"

## 二、高频行为题 + 出题意图

| 类别 | 高频题 | 面试官真正想看什么 |
|------|--------|------------------|
| 自我介绍 | "做个自我介绍" | 逻辑、亮点提炼、岗位匹配 |
| 项目深挖 | "挑一个最能代表你能力的项目讲讲" | STAR 完整性、个人贡献、技术深度 |
| 失败复盘 | "讲一次失败/踩坑的经历，怎么解决的" | 诚实度、成长性、反思能力 |
| 冲突处理 | "和同事/上级有分歧怎么办" | 沟通 + 职场成熟度 |
| 压力/多任务 | "同时多个任务赶不上怎么办" | 优先级判断、情绪稳定 |
| 职业规划 | "未来 3 年规划" | 目标感、学习方向、是否匹配岗位 |
| 离职/动机 | "为什么离开上家 / 为什么想来我们这" | 候选人主动表达的诉求与岗位匹配 |
| 优缺点 | "你最大的缺点是什么" | 自我认知、是否真诚 |
| 加班态度 | "怎么看加班" | 价值观、边界感 |
| 期望薪资 | "期望薪资多少" | 市场认知、谈判素质 |

## 三、参考答案框架（复盘时给出）

**自我介绍（60-90 秒版）**：一句话定位（几年经验/专长）+ 2-3 个核心亮点（用数据支撑）+ 为什么匹配这个岗位 + 简短职业目标。

**失败复盘**：坦诚选一件真事 → 说明当时判断失误在哪 → 你采取的行动 → 客观结果 → 沉淀出的方法论（避免甩锅他人）。

**最大缺点**：选一个"真实但非致命"的缺点 + 你已经在做的改进动作（例："我有时过度追求细节，现在会用固定排期和对齐节点来约束自己"）。

**期望薪资**：仅在用户选择薪酬沟通练习时讨论。可以根据用户目标给区间、总包结构和谈判策略，但不要要求披露当前薪资，也不要套用“薪资可谈、更看重成长”的固定答案。

## 四、反问环节

面试末尾可问："你有什么想问我的吗？" 评价问题是否清晰、与用户决策相关，而不是按主题高低打分。询问薪酬福利、工作节奏和劳动条件与询问业务、团队、发展同样合理。可提供以下反问示例：
- "团队目前最想解决的技术/业务难题是什么？"
- "这个岗位前三到六个月的考核标准是什么？"
- "团队的工作节奏和协作方式是怎样的？"

## 五、HR 面特色追问

只有用户明确选择 HR、薪酬或 offer 沟通练习时，才使用相关问题：

- 求职选择："你选择下一份工作的主要标准是什么？"
- 薪酬："你对目标岗位的薪酬范围和总包结构有什么期望？"
- 时间线：只核对与岗位经历直接相关的事实，不要求解释私人生活，不根据空档期推断能力或稳定性。
- Offer 情况：允许用户拒答；不以是否拥有其他 offer 判断竞争力、诚意或得分。

年龄、婚育、家庭、健康、宗教、政治、薪资历史等敏感信息不是能力评分依据。用户跳过敏感题不扣分。
