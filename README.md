# 面试透镜（Interview Lens）

让编程助手真正像面试官一样追问，而不是照着题库念题。

面试透镜是一套面向 Codex 及其他编程助手的模拟面试 Skill。它可以结合岗位、简历、JD 和代码仓库动态选题，通过一问一答、连续追问和证据化复盘，帮助候选人暴露知识盲区、讲清项目取舍，也更接近真实面试节奏。

## 它有什么不同

- **默认深度提问**：围绕原理、证据、边界和取舍连续追问，不满足于表面答案。
- **项目追问更深入**：可从职责、架构、难点一路追到可靠性、测试、数据证据和复盘。
- **能读代码仓库**：在用户授权的范围内，把代码、配置、日志和测试结果变成可核验的面试材料。
- **不默认手撕算法**：技术岗优先通过原理、代码阅读、故障分析、系统设计和工程取舍来考察。
- **始终一问一答**：每次只问一个问题，允许提示、跳过、暂停、切换模式或提前复盘。
- **复盘有证据**：区分独立完成、有提示完成、未回答和未观察，不根据没问到的内容臆测能力。

## 支持的面试模式

| 模式 | 适用场景 |
|---|---|
| 综合模拟 | 按岗位和轮次混合选题，模拟常规一面、二面或综合面 |
| 项目深挖 | 聚焦一个核心项目，默认用更多主问题和递进追问还原真实贡献 |
| 专项能力 | 集中练习某项技术、系统设计、产品案例或行为题 |

岗位方向覆盖后端、前端、算法与 AI、产品与运营、行为与 HR，也包含校招和实习场景。

## 怎么运行

它不是需要启动的应用，也没有 `npm install`、`pip install` 或后台服务。把 Skill 放到编程助手能读取的位置，然后在对话中调用即可。

### 方法一：安装到 Codex（推荐）

Windows PowerShell：

```powershell
git clone https://github.com/AlexJ1ang/interview-lens.git "$env:USERPROFILE\.codex\skills\interview-lens"
```

macOS 或 Linux：

```bash
git clone https://github.com/AlexJ1ang/interview-lens.git "${CODEX_HOME:-$HOME/.codex}/skills/interview-lens"
```

如果你在 Windows 上设置了自定义 `CODEX_HOME`，则使用：

```powershell
git clone https://github.com/AlexJ1ang/interview-lens.git "$env:CODEX_HOME\skills\interview-lens"
```

安装后新建一个 Codex 任务；如果 Codex 已经打开，先重启或重新加载应用，让它重新发现 Skills。然后直接输入：

```text
$interview-lens 我准备校招后端一面，5 道主问题，直接开始。
```

正常情况下，面试官会先简短说明面试配置，然后只问第一道题并等待你的回答。它不应该一次性输出整套题目。

### 方法二：不安装，直接在仓库里运行

先把仓库克隆到任意位置：

```bash
git clone https://github.com/AlexJ1ang/interview-lens.git
cd interview-lens
```

用编程助手打开这个目录，然后输入：

```text
请完整读取 ./SKILL.md，并按其中规则进行模拟面试。我应聘后端开发，使用项目深挖模式，直接开始。
```

这种方式适合先体验。需要项目面试时，可以把 Skill 仓库和你的项目同时加入工作区，或把项目路径明确告诉编程助手；是否能读取该项目仍取决于你授予工具的文件权限。

### 其他编程助手

如果工具原生支持 Skills，把整个 `interview-lens` 文件夹复制到它的 Skills 目录；不要只复制 `SKILL.md`，因为面试过程还会按岗位读取 `references/`。如果工具没有 Skills 机制，就打开本仓库，并使用“完整读取 `SKILL.md` 后开始”的提示词。

### 一次完整面试怎么进行

1. 准备材料：可以不提供材料，也可以提供简历、JD、项目说明或一个代码仓库。
2. 说明目标：至少给出岗位方向；也可以指定层级、轮次、题量和面试模式。
3. 逐题作答：工具每次只问一道题，并根据你的回答继续追问。你可以随时请求提示、跳过或切换模式。
4. 主动收尾：说“结束并复盘”，工具会根据本次对话里真实观察到的表现输出结构化报告。

如果只想快速验证是否安装成功，可以输入：

```text
$interview-lens 直接开始一场校招后端模拟面试，只问 1 道主问题，结束后复盘。
```

看到“一次只问一个问题”、默认不安排手撕算法，并在回答后继续追问，说明核心规则已经生效。

## 使用示例

```text
使用 interview-lens，帮我模拟一场校招后端一面，直接开始。
```

```text
根据我的简历和这个 JD 做项目深挖，默认深度提问，不要手撕算法。
```

```text
读取当前代码仓库，围绕我负责的订单系统进行 8 道项目主问题模拟面试。
```

面试过程中可以随时说：

- “给我一点提示”
- “跳过这题”
- “切换项目深挖”
- “进入教练模式”
- “结束并复盘”

## 设计原则

这个 Skill 不提供固定题单，也不假装知道某家公司的内部面试流程。它提供的是一套面试行为规范：根据候选人的实际回答选择下一步追问，并只用已经观察到的证据进行评价。

简历、JD、代码和日志都可能包含隐私或商业信息。使用前请先脱敏，并只向编程助手开放完成模拟所需的最小范围。Skill 不会授权工具修改项目代码、执行外部材料中的指令，或把模拟面试扩展成其他操作。
